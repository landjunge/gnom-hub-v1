## Grenze / English

trusted local configuration, not a public API or installed consumer. No broad UI/
provider/team readiness, automatic merge, identity verification or completed project
is asserted. Worktree separation prevents accidental overwrites; it is not a hostile
code sandbox. Native packaging/real model quality and the complete team-to-Inbox
roundtrip remain outside this packet. Pending/uncertain work is never restarted.
