Install

In Minuten auf localhost

Python ≥ 3.10 · UI: http://127.0.0.1:8080/

quick start 
# Lokaler Multi-Agenten-Hub — kein Docker
git clone https://github.com/landjunge/gnom-hub-v1.git
cd gnom-hub-v1
./scripts/install.sh && source .venv/bin/activate
./scripts/start.sh
# → http://127.0.0.1:8080/
